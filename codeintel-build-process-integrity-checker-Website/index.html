Watch 1

Files Against Their Hashes

codeintel-build-process-integrity-checker verifies the integrity of the build process by checking build scripts, dependency files, and compiler settings files against supplied SHA256 baseline hashes, and alerts on mismatches.

The Build Script Comes First

The build script is the primary artifact: a named build script with no baseline hash exits 1. Any other named file with no baseline hash is logged as skipped, one line per file, and a closing summary counts checked and skipped files.

Skipped Is Logged, Never Silent

A run that checked zero files exits 1. If a scanner the operator asked for is missing or returns non zero, the run ends with a line naming the scanner outcomes and exits 1.

Watch 5

What an Actual Run Does

A named file with a baseline hash gets checked against that hash; a mismatch raises an alert. A named build script without a baseline ends the run at exit 1 at once, whereas any other named file without a baseline is logged as skipped, one line per file. At the close, a summary counts checked and skipped files, and a run that checked zero files exits 1 rather than passing in silence.

When a Scanner Fails

A scanner asked for with --run-bandit, --run-flake8, --run-pylint, or --run-pyre that is missing or returns non zero ends the run with a line naming the scanner outcomes and exit 1.
