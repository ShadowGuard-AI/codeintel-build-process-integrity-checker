codeintel-build-process-integrity-checker

The Proving House. A command line checker that stretches each named build file against the SHA256 baseline hash supplied for it, counts what it checked and what it skipped, and fails the run when a tested file does not match its record.

The repository main.py
Primary artifactThe build script, named with --build-script, which is required by the parser
CheckThe SHA256 of each named file is compared with the baseline hash supplied for it
SummaryEach run closes with a count of files checked and files skipped
ScannersBandit, flake8, pylint, and pyre run only when their flags are given

Usage

python3 main.py --build-script FILE [--dependency-file FILE] [--compiler-settings FILE] [--baseline-hash-* HASH] [--run-bandit] [--run-flake8] [--run-pylint] [--run-pyre] [--offensive-scan]

Each named file takes its own baseline hash argument. Nothing is compared against anything the operator did not supply: with no baseline for a file there is no check on it at all.

OptionWhat it does
--build-scriptThe primary file to verify. Required. A named file that does not exist exits 1 before anything is checked, and a build script with no baseline is an error and exits 1.
--dependency-file / --compiler-settingsFurther named files. One with no baseline is logged as skipped, one line per file.
--baseline-hash-*The supplied SHA256 baseline for its file. A mismatching hash fails the run with exit 1, and a run that checked zero files also exits 1.
--run-bandit / --run-flake8 / --run-pylint / --run-pyreRun that scanner against the build script itself; pyre alone runs pyre check in its own project directory. A missing or non zero scanner ends the run with a scanner outcomes line and exit 1.
--offensive-scanThe README gives this flag No description provided and explains it nowhere. Verified in the code, its only effect is to append -lll to the bandit command; the flake8, pylint, and pyre commands are unchanged by it.

What a pass means

  • A pass means every checked file matched the baseline its operator supplied. Files without baselines are skipped, not verified.
  • The summary counts checked and skipped files; read it before trusting the exit code alone.

Requirements

Python, plus bandit, flake8, pylint, and pyre-check, each 1.0.0 or later, for the scanner flags.
